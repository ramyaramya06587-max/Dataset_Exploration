# Task 17: Dataset Exploration

## Introduction
Dataset exploration is an important step in data analysis. It helps us understand the structure, dimensions, data types, and basic characteristics of a dataset before further analysis or machine learning.

## Objective
To explore a dataset using Python and Pandas, identify numerical and categorical columns, and examine descriptive statistics.

## Tools and Technologies
- Python
- Pandas
- Jupyter Notebook

## Dataset Description
The Iris dataset is used for this task. It contains measurements of Iris flowers belonging to three species: Setosa, Versicolor, and Virginica.

The dataset contains the following columns:
- `sepal_length` – Length of the sepal.
- `sepal_width` – Width of the sepal.
- `petal_length` – Length of the petal.
- `petal_width` – Width of the petal.
- `species` – Species of the Iris flower.

## Tasks Performed
1. Loaded the Iris dataset using Pandas.
2. Displayed the first five and last five records.
3. Checked the number of rows and columns.
4. Examined column names and data types.
5. Identified numerical and categorical columns.
6. Generated descriptive statistics using `describe()`.
7. Checked missing values and unique values.
8. Examined the distribution of flower species.
9. Calculated average measurements for each species.
10. Recorded observations based on the dataset.

## Key Observations
1. The dataset contains 150 rows and 5 columns.
2. It contains four numerical columns and one categorical column.
3. There are three Iris flower species.
4. The dataset has no missing values.
5. The average flower measurements differ across species.

## Conclusion
This project demonstrates how to perform basic dataset exploration using Python and Pandas. The analysis provides an understanding of the dataset's structure, data types, missing values, and statistical characteristics.
